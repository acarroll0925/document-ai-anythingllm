# Juniper Table Catering Co. — New Hire Onboarding Checklist

*The Operations Manager works through this list with every new hire. Nothing here is optional or out of order.*

## Before Day One

- [ ] Signed offer letter returned (position and pay rate are set there — see the Employee Handbook, Section 5)
- [ ] I-9 and W-4 completed; direct deposit form filed
- [ ] Copy of driver's license on file (required for anyone who may drive — see the Delivery & Vehicle Policy)

## First Week

- [ ] Uniform issued: two black Juniper Table polos; non-slip shoes are the hire's own responsibility
- [ ] Kitchen tour: allergen station (blue board), dry storage, cooler layout, cubbies
- [ ] Read the **Food Safety & Allergen Policy** and sign the acknowledgment page — including the nut allergy procedure in Section 4
- [ ] Read the **Incident Report Procedure**; locate Form IR-1 in the event binder
- [ ] Georgia food handler card obtained **within the first 14 days**; card copy to the Operations Manager

## First Two Events

- [ ] Shadow **two full events** with an experienced staff member before working a solo station
- [ ] Practice run: set and break down one station against the Run-of-Show clock
- [ ] Ride-along on one delivery run (required before the supervised driving checkout)

## Sign-Off

- [ ] Operations Manager (Dana Whitfield) signs the completed checklist and files it in the hire's personnel folder
- [ ] Hire added to the scheduling app and the two-week posted schedule
